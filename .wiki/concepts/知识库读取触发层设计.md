## 问题与判据

主诉「dsh web 每次会话不积极查询知识库」的真相不是"没查"，而是主动查询只有一条很弱的路：注入一句**提示文本**（不含页面内容），而那次提示检索到的还是别的库（见 [[会话级知识库绑定]]）。

所以"什么时候查"的答案不是某个时刻，而是判据（三条缺一即退化为噪声）：

1. **最早可逆**——在改动还没落成不可逆之前；
2. **词面/语义重合度足够**——不足以判断相关就沉默；
3. **每任务至多一次**——同一任务重复提示只会变成噪声。

两条被实测否掉的直觉答案：

| 方案 | 实测证据 | 结论 |
|---|---|---|
| 每次 `edit/write` 前查库 | 改库触碰 1719 次 vs 读库 151 次 | 高频噪声，否 |
| `AGENTS.md` 常驻指令 | 4 个会话：2 例完整闭环，2 例**两天 0 次读库** | 常驻指令不是硬保证 |

还有一条代价基线："无匹配一次就足以教会模型这个库没用"——基线里 12 次同一多词查询全部 0 命中。

## 五层结构（最终状态）

| 层 | 判据 | 挂点 | 默认 |
|---|---|---|---|
| **L0 会话级库绑定** | 按会话 cwd 解析本工作区的库，注入库身份 | `agent/session-start` | 开 |
| **L1 一档** | 新任务原话词表命中 → top-3（标题 + 命中词 + frontmatter 摘要） | `agent/pre-step` | 开 |
| **L1 二档** | 一档在下一回合仍未被采纳（那回合完全没碰库）→ 追投该页**正文**（≤4800 字符） | 同上 | 开 |
| **L2 合取门** | **未检索过 且 目标路径命中高危集** → warn 放行 / block 拦一次 | `tools/pre-execute` | **off** |
| **L3 复发信号** | 同一失败签名出现 ≥2 次 → 提示"上次的办法没生效" | 回合边界折叠 `tool/result` | 开 |
| ~~L5 沉淀提醒~~ | 已整体移除，理由见 [[知识库写入侧零推动]] | — | — |

几处刻意的细节：

- L0 注入的是**库身份**（库名 + 页数 + 根目录 + 索引路径），实测 176 字符；空库不注入。
- L1 一档字面 0 命中才走**语义兜底**，且只接受**已热**的运行时（`requireWarm`）——冷启动几十秒绝不挂在 `pre-step` 上。
- L1 二档同回合不追投；跨重启按 `知识库提示全文#<seq>` 去重。**二档触发即"提示被忽略了"的免费度量**，注入了二档就是一次漏，不需要额外探头。
- L2 的高危集来源是**库内页面显式提到的路径/模块**加一个极小硬编码集（迁移、权限/授权、部署脚本、公共 API 签名）；**无库时高危集为空**（宁可不拦）。因为"这个路径高风险"最可靠的来源恰恰是知识库自己的页面，猜不出来的话就会退化成每次 edit 都拦——正是被否掉的那版。
- L2 是唯一"强"的一层（warn/block），噪声代价不对称：L1 多说是噪声，L2 多拦是**打断**。所以它排在最后，且等 L1 的真实跟进率数据出来再决定是否升 block。

## 明确不该查的时刻

每次 `edit`、每个回合、同一任务重复、库为空/未初始化、命中不足 2 词。

命中门槛是**静默失败**的：`MIN_TERMS = 2` + `MIN_SCORE = 1`，只命中 1 个词、空库、未初始化、无匹配 → 返回空数组，一个字都不注入。"帮我看看这个"这类话永远不会有提示。词面匹配对改写式提问天然无力（语义层只接在工具里，不接在主动路径上）。

## 开关与依赖顺序

- `KNJ_OBSIDIAN_TRIGGER_SUBAGENT=off` 收敛子代理触发（**默认子代理也触发**）。
- `KNJ_OBSIDIAN_GATE=off|warn|block`（默认 `off`）。
- 顺序不是平行的：**先 L0 再 L1 加强，最后 L3 / L2**。理由——如果会话仍绑在错的库上，加强的触发只会更响地答错。

## 验收指标

| 指标 | 口径 | 目标 |
|---|---|---|
| 跟进率 | 一档注入后 ≤2 步内是否读/查了提示的页 | ≥50% |
| 二档率 | 二档注入次数 / 一档注入次数 | 先测不设目标（漏的直接读数） |
| 假阳性 | 无关任务被注入 | ≤ 现有水平（离线 4/4 沉默不许退化） |
| 单任务预算 | 一档 + 二档 token | ≤1400 |
| L2 拦截命中率 | warn/block 后模型改为先查库的比例 | ≥50% |
| L2 误拦率 | 高危集命中但库里其实无相关内容 | ≤20% |
